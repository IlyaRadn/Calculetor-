# Работа над этим репозиторием

Файл читают Cursor, Claude Code и другие агенты. Правила короткие, потому что
длинные не соблюдаются.

## Что это

Калькулятор кредита с льготным периодом. Одна страница без фреймворка и без
сборщика: разметка, стили и логика лежат в `index.html` одним файлом.
Подробности продукта — [PRODUCT.md](PRODUCT.md), визуальная система —
[DESIGN.md](DESIGN.md).

## Первое правило

**Правки вносятся только в `index.html`.**

`docs/index.html` и `dist/credit-calculator.html` — сборка. Их перезаписывает
`node build.mjs`, и любая ручная правка там пропадёт при следующей сборке.
После изменения `index.html` собрать заново:

```bash
node build.mjs
```

`docs/` уезжает на GitHub Pages. `dist/` — самодостаточный файл для передачи
третьим лицам: без внешних ссылок и без личных данных в значениях по
умолчанию. Если правка добавляет внешнюю ссылку или подставляет в поля чьи-то
настоящие цифры, `build.mjs` тоже придётся поправить — иначе они уедут в
дистрибутив.

## Устройство index.html

У файла нет `<!doctype>`, `<html>` и `<head>` — это не ошибка. Исходник
рассчитан на Artifact в claude.ai, который добавляет обвязку сам. Для Pages и
для дистрибутива её достраивает `build.mjs`.

Порядок внутри: `<title>` и подключение шрифтов, затем `<style>` целиком,
затем разметка, затем `<script>`.

## Стиль кода

Как в файле рядом. Конкретно здесь это значит:

- Отступ два пробела, кавычки двойные, точка с запятой в конце.
- Комментарии по-русски и только там, где объясняют «почему», а не «что».
- Никаких зависимостей и сборщиков. Ванильный DOM API.
- Цвета, радиусы и тени — только через переменные из `:root`. Значение цвета,
  вписанное прямо в правило, ломает тёмную тему.

## Проверка перед коммитом

```bash
node build.mjs
```

Сборка падает, если структура `index.html` изменилась так, что скрипт её не
узнаёт. Это единственная автоматическая проверка в репозитории — открывать
`docs/index.html` в браузере всё равно нужно руками, и обязательно в обеих
темах и на узком экране.

## Скиллы агентов

В репозитории 16 скиллов — по дизайну, анимации и подготовке продукта к
передаче. Claude Code берёт их из `.claude/skills/`, Cursor — из
`.cursor/skills/`; папки держатся одинаковыми, источник — `.claude/skills/`.

```bash
node scripts/sync-skills.mjs          # привести .cursor/skills в соответствие
node scripts/sync-skills.mjs --check  # проверить, не разошлось ли
```

Что где лежит, как обновлять и откуда что взято — [SKILLS.md](SKILLS.md).

С чего начинать:

| Задача | Скилл |
|---|---|
| Оживить интерфейс, добавить движение | `/animate`, `/find-animation-opportunities` |
| Проверить уже сделанные анимации | `/review-animations` |
| Общий разбор и доводка вида | `/impeccable critique`, `/impeccable polish` |
| Свести переходы к единой шкале | `/motion-system` |
| Понять, что осталось до показа | `/mvp-ship-check` |

**Движение в этом проекте сдержанное** — это калькулятор, человек приходит
считать деньги. Правила и уже занятые анимации — в [DESIGN.md](DESIGN.md),
раздел «Движение». Читать до того, как добавлять новое.
