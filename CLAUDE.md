## Скиллы

Лежат в `.claude/skills/`, подхватываются сами. Зеркало для Cursor —
`.cursor/skills/`, обновляется командой `node scripts/sync-skills.mjs`.
После добавления или правки скилла зеркало обновить, иначе проверка в CI
не пройдёт.

## Детектор impeccable

Impeccable умеет проверять правки в интерфейсе своими правилами сразу после
записи файла. В репозитории эти хуки не включены: они запускают бинарник,
который скачивается при первом обращении, и молчаливая загрузка на чужой
машине — не то, что хочется получить, клонировав репозиторий.

Кому нужно — включается локально одной командой:

```bash
npx impeccable install --providers=claude,cursor --project --force
```

Она допишет `.claude/settings.local.json`, а он в `.gitignore` — то есть
настройка останется личной.

## Сборка

`node build.mjs` после любой правки `index.html`. Результат — `docs/index.html`
для Pages и `dist/credit-calculator.html` для передачи третьим лицам.
