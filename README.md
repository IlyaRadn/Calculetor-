# Кредитная ведомость

Калькулятор кредита в белорусских рублях с льготным периодом: первые годы платятся
фиксированный процент от суммы кредита и фиксированные проценты, затем остаток тела
и накопленные проценты раскладываются равными долями на оставшийся срок.

**Сайт:** https://ilyaradn.github.io/Calculetor-/

## Что умеет

- График по годам с раскрытием месяцев: основной долг, проценты в платеже, остаток,
  накопленный процентный долг.
- Досрочное погашение — разовое или ежемесячное, несколько взносов сразу.
  Сумма добавляется к платежу месяца и уменьшает тело кредита.
- Два сценария пересчёта: банк сокращает срок либо уменьшает платёж — с живыми
  цифрами по каждому.
- Все условия договора редактируются, введённое сохраняется в браузере.

## Как устроен репозиторий

| Файл | Назначение |
|---|---|
| `index.html` | Исходник. Без `<!doctype>`, `<html>`, `<head>` — эту обвязку добавляет Artifact на claude.ai. Правки вносятся сюда. |
| `docs/index.html` | Сборка для GitHub Pages. Не редактировать руками — перезаписывается. |
| `build.mjs` | Оборачивает исходник в полноценный HTML-документ: `meta viewport` (без неё не включается мобильная вёрстка), favicon, `noindex`. |

## Обновить сайт

```bash
node build.mjs
git add -A
git commit -m "Правка расчёта"
git push
```

Pages пересобирается около минуты. Если изменения не видно — Ctrl+F5, кэш браузера.

## Расчёт

Месячная ставка — `годовая / 12`: договор задаёт год в 360 дней, месяц в 30.
Проценты начисляются на остаток основного долга. В льготный период платится
фиксированная сумма, разница между начисленным и уплаченным копится; по окончании
периода этот долг делится на оставшиеся месяцы и входит в платёж.
При полном досрочном погашении накопленный процентный долг закрывается целиком.
